# 🐕 柴柴账本 shiba-budget

一个黄油色柴犬主题的手机记账小工具，可以单手用，能添加到手机桌面当 App 用。

- 澳币版（AUD）：https://zizhu10y.github.io/shiba-budget/
- 人民币版（CNY）：https://zizhu10y.github.io/shiba-budget/cny/

## 能做什么

- **首页**：大字显示还能花多少，以及每天可花、今天还能花；快超支时会提醒
- **记一笔**：点右下角 ＋，用数字键盘输入金额，选一个分类就记好了（＋ 只在首页出现）
- **收入**：两种方式
  - 固定收入：填金额和频率，首页按月算「这个月还能花」，月底剩下的钱自动放进小金猪
  - 每周不固定：每次到账记一笔收入，整个 App 按周算（见下面）
- **固定支出**：房租、话费等，按「每周 × 52 ÷ 12」换算成每月；收入不固定时每周扣一周的份
- **交房租提醒**：在设置里填最近一次交租日期，交租前 2 天首页会提醒，也可以加到手机日历
- **总览**：
  - 收入不固定时是「周 | 月 | 年」：周看每周收入、花销和结余；月只看收入和花销（分类可以点开看每一笔）；年看每月收入和支出的柱状图
  - 固定收入时是「月 | 年」
- **存钱**：
  - 🐷 小金猪：放你的全部积蓄。存入、取出只要填金额；以前就有的存款用「＋ 记录以前的存款」
  - 🦴 存钱目标：带进度条，可以设截止日期，分「必须完成」和「不着急」两页，用 ↑↓ 排顺序

### 收入每周不固定时怎么算

一条规则：

> 这周还能花 = 这周收入 − 这周固定支出 − 花的 − 存的

- 一周从哪天开始可以在「设置 → 收入」里选，这一天扣一周的固定支出
- 每天可花 = 这周还能花 ÷ 这周剩几天
- 这周的钱不够时，首页温和地显示「还差 $X」（不是红色负数），要不要从小金猪补，由你点按钮决定；补了就算这周用掉了
- 一周过完，剩下的钱自动存进小金猪
- **深色模式**：跟随手机系统自动切换
- **备份**：在设置里导出或导入 JSON 文件

## 数据存在哪里

所有数据都只保存在**你自己手机的浏览器里**（localStorage），不会上传到任何服务器。这个仓库是公开的，但别人只能看到代码，看不到任何人的账。

所以要注意：
- 每个人、每台手机的数据是分开的，多人可以各用各的
- 清除浏览器数据或换手机前，请先在「设置」里**导出备份**，到新手机上再导入

## 添加到手机桌面

**iPhone（Safari）**：打开网址 → 点底部的分享按钮 → 「添加到主屏幕」

**安卓（Chrome）**：打开网址 → 点右上角 ⋮ → 「添加到主屏幕」或「安装应用」

## 本地运行

不需要安装依赖，也没有构建步骤：

```bash
node serve.js
```

然后打开 http://localhost:8123 。同一个 Wi-Fi 下的手机，可以用电脑的局域网 IP 加 `:8123` 访问。

## 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 澳币版页面 |
| `cny/index.html` | 人民币版页面（和澳币版共用同一份 `app.js` 和 `style.css`） |
| `app.js` | 全部功能逻辑 |
| `style.css` | 样式、柴犬主题、深色模式 |
| `sw.js` | Service Worker，负责离线可用和自动更新 |
| `manifest.webmanifest` | 添加到桌面用的 App 信息 |
| `icons/` | 柴犬 App 图标 |
| `serve.js` | 本地预览用的小服务器 |

## 发布更新

推送到 `main` 分支后，GitHub Pages 会自动部署。每次发布前，记得把 `sw.js` 里的 `CACHE` 版本号加 1，这样已经装到桌面的 App 会自动更新。
